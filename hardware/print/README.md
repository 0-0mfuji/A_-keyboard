# 印刷データ（case v7） — QIDI Tech X-Plus / PLA Matte

`hardware/freecad/build_case_v7.py` を実行すると、このフォルダのファイルがすべて作り直されます。
メッシュは弦誤差0.01mm・角度3°で細かく出力しているので、曲面の多角形感は出ません。

## ファイル

| ファイル | 内容 | 向き |
|---|---|---|
| `plate1_case_left.3mf` | 左ケース | 傾いた底面を下（机に置く向きのまま） |
| `plate2_case_right_cover.3mf` | 右ケース＋ボールカバー | ケースは底面を下、カバーは根元を下 |
| `v7_case_left.stl` / `v7_case_right.stl` / `v7_ball_cover.stl` | 1パーツずつ（向きは上と同じ） | |

3MFはそのままの配置で、X-Plusのベッド（270×200mm）に収まります。**向きは変えないでください**。
QIDI Print と OrcaSlicer のどちらでも読み込めます。

## おすすめ設定（PLA Matte、0.4mmノズル）

| 項目 | ケース（左右） | ボールカバー |
|---|---|---|
| 積層ピッチ | 0.12mm＋アダプティブ積層（可変積層）ON | 0.08〜0.10mm |
| 壁の数 | 4（1.6mm） | 4 |
| 上面／下面の層数 | 7 / 5 | 7 / 5 |
| インフィル | 15〜20% ジャイロイド | 20% ジャイロイド |
| 壁の順序 | 内→外（または 内-外-内） | 同左 |
| シーム位置 | 背面（Back）に揃える | 背面 |
| 外壁速度 | 40mm/s 以下 | 30mm/s 以下 |
| ノズル／ベッド温度 | 210℃ / 60℃ | 同左 |
| ファン | 3層目から100% | 同左 |
| エレファントフット補正 | 0.15mm | 0.15mm（受け座へのはまりに影響します） |
| ブリム | 5mm（任意。角が丸いので付けると安心） | なし |
| アイロニング | OFF（上面が4°傾いているため効きません） | OFF |

**サポート**
- 右ケース：必要です。トラックボールのカップの裏（センサー基板を吊る面）が、ケース内部で宙に浮いています。
  - 種類：ツリー（またはノーマル）
  - 生成範囲：どこでも（Everywhere）
  - オーバーハング角：50°
  - Z距離：0.2mm
  - インターフェース：ON
  - サポートが付くのはケースの内側だけなので、外から見える面には跡が残りません。
- 左ケース：不要です（内側の張り出しはブリッジで印刷できます）。
- カバー：不要です。磁石穴はベッド側に開いています。

**質感を上げるコツ**
- アダプティブ積層を使うと、丸い角や緩い斜面の段差（等高線状の線）が目立ちにくくなります。
- マット系PLAは積層痕が目立ちにくい材料です。さらに滑らかにしたい場合は、#400→#800の耐水ペーパーで軽く研いでください。

## 先にカバーを試し刷りしてください

カバーは小さく（約50mm角、1時間程度）、はめ合いの確認に向いています。

1. ボール（34mm）がふちの開口（設計Φ33.5）から抜けず、回したときにこすらないか確認します（設計上のすき間は0.2mm）。
2. こすれる場合は、`COVER_LIP_R` を +0.05〜0.1 して作り直します。抜けそうな場合は −0.05 します。
3. ケースの受け座（すき間0.3mm）にスッと入るか確認します。
